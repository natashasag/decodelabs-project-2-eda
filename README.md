# DecodeLabs Project 2 – Exploratory Data Analysis

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a cleaned e-commerce dataset.

The objective was to understand the dataset through descriptive statistics, trend analysis, product analysis, order analysis, and outlier investigation.

The analysis helps identify patterns and useful insights before applying advanced analytical techniques.



## 🎯 Objectives

- Understand the characteristics of the dataset
- Calculate basic descriptive statistics
- Identify important trends
- Analyze product performance
- Analyze order status and payment methods
- Identify potential outliers
- Extract meaningful business observations
- Present findings using charts

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables / Excel Analysis
- Data Visualization
- Exploratory Data Analysis

---

## 📂 Dataset

The dataset contains e-commerce/order information including:

- Order ID
- Date
- Product
- Quantity
- Unit Price
- Total Price
- Payment Method
- Order Status
- Coupon Code
- Other order-related attributes

---

## 🔍 Analysis Performed

### 1. Basic Statistics

Descriptive statistics were calculated to understand the dataset.

The analysis included:

- Count
- Mean
- Median
- Minimum
- Maximum
- Other supporting statistics

---

### 2. Trend Analysis

The dataset was analyzed over time to identify changes in:

- Number of orders
- Sales
- Monthly performance
- Yearly performance

---

### 3. Product Analysis

Products were compared based on:

- Number of orders
- Sales
- Quantity
- Overall performance

---

### 4. Order Status Analysis

Order statuses were analyzed to understand the distribution of different order outcomes.

---

### 5. Payment Method Analysis

Different payment methods were compared based on order activity and sales.

---

### 6. Outlier Analysis

The Interquartile Range (IQR) approach was used to identify unusually high or low observations.

Outliers were identified for investigation rather than automatically removing them.
